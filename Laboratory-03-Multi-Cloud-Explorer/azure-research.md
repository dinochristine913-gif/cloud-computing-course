# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft. 
It provides services that businesses and organizations can use for applications, 
storage, databases, networking, and other IT needs.

## Global Infrastructure
Azure has cloud infrastructure in many parts of the world. It uses Regions and 
Availability Zones to help organizations run their applications reliably. 
Having resources in different locations also helps businesses provide better access to 
users in different areas.

## Cloud Management Console
The Azure portal is the main website used to manage Azure services. Users can use it to 
create and manage resources such as virtual machines, databases, storage, and networks. 
It also provides tools for monitoring and managing cloud resources.

## Four Core Services
Azure Virtual Machines – Used to run virtual computers in the cloud.
Azure Blob Storage – Used to store large amounts of files and other data.
Azure SQL Database – Used for managing relational databases in the cloud.
Azure Virtual Network – Used to connect and manage network resources in Azure.

## Three Advantages
Microsoft integration – It works well with Microsoft products such as Windows Server and Microsoft 365.
Scalability – Resources can be adjusted as the organization's needs change.
Enterprise support – Azure provides services and tools designed for organizations and businesses.

## Typical Enterprise Use Cases
Azure can be used by businesses for hosting applications, running Windows servers, 
managing databases, storing data, and creating hybrid cloud systems. It is also a good option for 
organizations that already use Microsoft products.
