# Mission Reflection

After completing this laboratory activity, I learned more about the differences between AWS, 
Microsoft Azure, and Google Cloud Platform. Before doing this activity, I mainly knew them as popular cloud providers, 
but researching their services helped me understand that each platform has its own strengths.

The cloud platform that impressed me the most was AWS because it offers many different services that can be used for various business needs. 
I also noticed that AWS can support both small businesses and large organizations.
However, Azure is also a good option for organizations that already use Microsoft technologies, 
while Google Cloud is strong in artificial intelligence, machine learning, and Kubernetes.

AWS, Azure, and GCP have many similarities because they all provide services for computing, storage, 
databases, networking, and other cloud needs. They also allow organizations to scale their resources depending on their requirements. 
Even though their services have different names, many of them have similar purposes.

Business requirements are important when choosing a cloud provider because there is no single provider that is best for every organization. 
A company needs to consider its budget, existing technologies, technical requirements, scalability, and the type of applications it wants to run.

Acting as a Cloud Solutions Consultant helped me understand that choosing a cloud provider is not simply about selecting the most popular platform. 
The decision should be based on the actual needs of the client and how the provider can solve their problems.

This laboratory also improved my GitHub Cloud Computing Portfolio because I added more organized research, comparisons, recommendations, and screenshots. 
It helped me practice documenting technical information using Markdown and made my portfolio more complete and organized.
