# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP), also known as Google Cloud, 
is a cloud computing platform provided by Google. 
It offers services for computing, storage, databases, networking, 
artificial intelligence, and application development.

## Global Infrastructure
Google Cloud has regions and zones located in different parts of the world. 
This allows businesses to run their applications closer to their users. 
Its global infrastructure also helps support applications that need
good performance and reliable connectivity.

## Cloud Management Console
The Google Cloud console is a website used to manage Google Cloud services. 
Users can use it to create and manage resources, monitor their applications, 
control access, and manage their cloud projects.

## Four Core Services
Compute Engine – Used to create and run virtual machines.
Cloud Storage – Used to store files and other types of data.
Cloud SQL – Used to manage relational databases.
Google Kubernetes Engine (GKE) – Used to deploy and manage applications using Kubernetes.

## Three Advantages
Strong AI and machine learning tools – Google Cloud has many services for AI and machine learning.
Kubernetes support – GKE makes it easier to deploy and manage Kubernetes applications.
Global network – Google Cloud has infrastructure in many locations around the world.

## Typical Enterprise Use Cases
Companies can use Google Cloud for application hosting, data analytics, artificial intelligence, 
machine learning, and containerized applications. It is also useful for businesses that 
need scalable systems and services that can handle large amounts of data.
