# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a cloud platform that provides different services that organizations can use over the internet. 
It can be used for running applications, storing files and data, managing databases, and many other cloud computing needs.

## Global Infrastructure
AWS has data centers located in different parts of the world. These are organized into Regions and Availability Zones. 
This setup helps businesses run their applications in different locations and keep their services available even when
problems occur in one location.

## Four Core Services
Amazon EC2 – Used to create and run virtual servers in the cloud.
Amazon S3 – Used to store and retrieve files and other types of data.
Amazon RDS – Used to create and manage relational databases.
AWS Lambda – Allows users to run code without managing a physical server.

## Three Advantages
Many services – AWS offers a wide variety of services for different needs.
Scalable – Resources can be increased or decreased depending on the workload.
Global infrastructure – Businesses can use AWS services in different parts of the world.

## Typical Enterprise Use Cases
Businesses can use AWS to host websites and applications, store important data, manage databases, create backups, 
and support large online systems. It can also be used by companies that need their applications to serve users from 
different locations.
